# 💧 Controle de Níveis de Água

Projeto desenvolvido em Python para simular o monitoramento dos níveis de água de um reservatório, utilizando mensagens coloridas no terminal para representar diferentes situações.

🎯 Objetivo

Desenvolver um programa simples que identifique e exiba os níveis de água de um reservatório com cores diferentes, facilitando a visualização de cada situação.

🛠️ Tecnologias utilizadas

Python: linguagem utilizada no desenvolvimento.

Colorama: biblioteca utilizada para colorir as mensagens exibidas no terminal.

⚙️ Funcionalidades

Armazenamento dos níveis em uma lista.

Utilização de uma função para definir a cor de cada nível.

Exibição de mensagens coloridas no terminal.

Restauração do estilo padrão após cada mensagem.

▶️ Como executar

1. Clone o repositório

git clone https://github.com/gustavoacrani/controle-de-niveis-de-agua.git

2. Entre na pasta do projeto

cd controle-de-niveis-de-agua

3. Instale a biblioteca Colorama

pip install colorama

4. Execute o programa

python app.py
